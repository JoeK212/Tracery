TRACERY is a browser tool for exploring the geometry of architectural windows. It draws the compass construction of each head in 2D and extrudes the same geometry into a 3D model with stone, tracery and glass layers, side by side.

It covers Romanesque, Gothic, Tudor, Moorish and Mamluk heads, rose and wheel windows, Islamic lattice screens, Art Nouveau warped grids, Mondrian compositions and Modulor Red and Blue series grids. Every parameter is a live control, and the analysis strip reports the numbers that define the form: rise-to-span ratio, radii as multiples of the span, apex angle and glazing ratio.

A Compare view sets a Modulor grid against a Mondrian composition on the same opening and measures how each uses proportion. Lengths can be shown in millimetres or feet-inches.

The Help button opens a guide with a Student, Designer and Professional explanation of the math, with the current window plugged into each formula. The guide also opens on a phone, although the tool itself needs a tablet or desktop screen.

The app is a single index.html with no build step. Open it in a browser, or deploy the folder to Netlify. Run node audit_deploy.js before any change is called done.
